# 脚本结构图

> 本文档随 `Assets/Scripts/` 下脚本的增改而更新，用于快速查看重制版分层与各脚本职责。

## 分层概览

```
Bootstrap/Presentation        运行入口、场景校正、退出保存
          ↓
UI/Presentation               标题场景与游戏场景面板、面板注册与导航
          ↓
Card / Inventory / Level      应用服务与领域配置（建造、仓库、编队、关卡）
          ↓
Common                        账号、货币、本地路径、加密、资源加载等基础服务
          ↓
Core / Debug                  编辑器工具与运行时调试辅助
```

- **Bootstrap/Presentation**：负责启动、强制入口场景、应用暂停/退出时触发统一保存。
- **UI/Presentation**：负责面板生命周期、按钮事件、列表渲染和场景跳转，不直接持久化文件。
- **Card / Inventory / Level**：承载卡牌建造、卡牌仓库、编队、背包、关卡数据等业务规则与 ScriptableObject 配置。
- **Common**：提供账号、货币、加密、本地存档路径、Resources 资源加载等跨模块基础能力；玩家进度按当前账号隔离保存。
- **Core / Debug**：提供 ScriptableObject 重命名工具和 UI 射线调试热键。

## 目录与脚本说明

### Assets/Scripts/

项目 C# 脚本根目录，当前重制版主要按 `Game/` 命名空间式目录组织。

### Assets/Scripts/Game/Bootstrap/Presentation

运行入口层，处理进入游戏前后的全局流程。

| 脚本 | 功能 |
|------|------|
| **GameBootstrap.cs** | 游戏启动器：确保运行时从标题场景进入，并在暂停/退出时调用统一保存。 |
| **GameSceneManager.cs** | 游戏场景管理入口：负责游戏主场景初始化与默认面板显示。 |

### Assets/Scripts/Game/Common

跨模块基础服务层，提供账号、资源、存档路径、加密和 Resources 加载。

| 脚本 | 功能 |
|------|------|
| **GameResourceLoader.cs** | 统一加载卡牌、道具、关卡、卡池等 Resources 数据库资源。 |
| **GameResourcePaths.cs** | 统一维护 Resources 下数据库资源路径常量。 |

#### Game/Common/Auth

账号数据与登录状态服务。

| 脚本 | 功能 |
|------|------|
| **AccountStore.cs** | 本地账号库：注册、登录、登出、记住密码；账号库保存为共享文件，供进度存储读取当前账号。 |

#### Game/Common/Currency

玩家货币数据服务。

| 脚本 | 功能 |
|------|------|
| **CurrencyStore.cs** | 金币、钻石、船票的读取、保存、增减；按当前账号隔离存储并校验自动保存所属账号。 |

#### Game/Common/Save

本地保存入口与路径工具。

| 脚本 | 功能 |
|------|------|
| **GameDataSaveService.cs** | 统一退出/后台保存入口；未登录时跳过玩家进度保存，避免默认缓存覆盖存档。 |
| **LocalUserDataPaths.cs** | 本地用户数据路径工具：账号库走共享目录，货币/背包/卡牌仓库/编队走账号哈希目录。 |

#### Game/Common/Security

本地数据加密基础设施。

| 脚本 | 功能 |
|------|------|
| **LocalDataCrypto.cs** | AES-CBC 加解密工具：把本地 JSON 存档加密为二进制文件。 |

### Assets/Scripts/Game/Card/Application

卡牌应用服务层，负责建造流程、卡牌仓库和编队持久化。

| 脚本 | 功能 |
|------|------|
| **BuildService.cs** | 建造服务：校验并扣除资源，按卡池权重抽卡，写入卡牌仓库。 |
| **CardCollectionStore.cs** | 卡牌仓库持久化：按当前账号保存拥有的 cardId 与数量，并阻止切号缓存误写。 |
| **FleetStore.cs** | 编队持久化：按当前账号保存多套卡组，首次无文件时从该账号卡牌仓库生成默认编队。 |

### Assets/Scripts/Game/Card/Domain

卡牌与建造领域配置层，主要为 ScriptableObject 和枚举。

| 脚本 | 功能 |
|------|------|
| **BuildPoolConfigSO.cs** | 单个建造卡池配置：展示信息、消耗、阵营过滤和掉落权重。 |
| **BuildPoolDatabaseSO.cs** | 卡池数据库：集中引用全部可用卡池配置。 |
| **CardConfigDatabaseSO.cs** | 卡牌配置数据库：集中引用全部卡牌配置。 |
| **CardConfigSO.cs** | 单张卡牌配置：id、名称、稀有度、阵营、图标等静态数据。 |
| **ShipFaction.cs** | 舰船阵营枚举及显示名扩展。 |

### Assets/Scripts/Game/Inventory/Application

背包应用服务层，负责玩家道具数据持久化。

| 脚本 | 功能 |
|------|------|
| **InventoryStore.cs** | 道具仓库持久化：按当前账号保存 itemId、显示名与数量，并阻止切号缓存误写。 |

### Assets/Scripts/Game/Inventory/Domain

道具领域配置层。

| 脚本 | 功能 |
|------|------|
| **ItemConfigDatabaseSO.cs** | 道具配置数据库：集中引用全部道具配置。 |
| **ItemConfigSO.cs** | 单个道具配置：id、显示名、描述、图标、品质等静态数据。 |

### Assets/Scripts/Game/Level/Domain

关卡领域配置层。

| 脚本 | 功能 |
|------|------|
| **LevelAreaConfigSO.cs** | 关卡区域配置：区域 id、名称、背景、关卡列表。 |
| **LevelAreaDatabaseSO.cs** | 关卡区域数据库：集中引用全部区域配置。 |
| **LevelStageConfigSO.cs** | 单个关卡配置：关卡 id、名称、消耗、奖励、解锁条件等。 |

### Assets/Scripts/Game/UI/Presentation

UI 基础设施与面板注册层。

| 脚本 | 功能 |
|------|------|
| **BasePanel.cs** | 面板基类：提供 PanelName、Show/Hide 与启停时注册逻辑。 |
| **PanelNames.cs** | 面板名和场景名常量。 |
| **UIPanelRegistry.cs** | 面板注册、栈式 Push/Pop、清栈、场景加载和退出游戏。 |

#### Game/UI/Presentation/TitleScene

标题场景 UI。

| 脚本 | 功能 |
|------|------|
| **TitlePanel.cs** | 标题面板：登录入口、登出、设置占位、退出游戏。 |
| **LoginPanel.cs** | 登录面板：账号输入、注册、登录、记住密码、进入游戏场景。 |
