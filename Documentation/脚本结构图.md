# 脚本结构图

> 本文档随 `Assets/Scripts/` 下脚本的增改而更新，用于快速查看当前重制版分层与各脚本/文件夹职责。

## 分层概览

```text
启动/场景层      Game/Bootstrap/Presentation
                    ↓
UI 表现层         Game/UI/Presentation
                    ↓
应用服务层        Game/Card/Application, Game/Inventory/Application, Game/Common/Currency, Game/Common/Auth, Game/Common/Save
                    ↓
领域配置层        Game/Card/Domain, Game/Inventory/Domain, Game/Level/Domain
                    ↓
通用基础设施      Game/Common, Game/Common/Security, Game/Core, Game/Debug
```

- **启动/场景层**：负责游戏入口、场景校正与应用暂停/退出时的统一保存。
- **UI 表现层**：负责面板注册、场景默认面板、标题登录、主界面、背包、建造、船坞、编队与关卡选择等交互表现。
- **应用服务层**：负责账号、本地存档、资源、卡牌仓库、建造抽卡、编队与背包等玩家数据读写和业务操作。
- **领域配置层**：通过 ScriptableObject 定义卡牌、卡池、道具、关卡区域与关卡阶段等静态配置。
- **通用基础设施**：提供资源路径、资源加载、加密、本地路径、编辑器工具与调试工具。

## 目录与脚本说明

### Assets/Scripts/

项目 C# 脚本根目录，当前重制版主要代码集中在 `Game/` 目录下，按 Bootstrap、Common、Card、Inventory、Level、UI 等模块组织。

---

### Assets/Scripts/Game/Bootstrap/Presentation

游戏启动与场景入口层，负责从任意场景运行时回到标题场景，并在应用退出或切后台时触发统一保存。

| 脚本 | 功能 |
|------|------|
| **GameBootstrap.cs** | 游戏启动器：常驻对象，强制入口场景为 `TitleScene`，并在退出/暂停时调用 `GameDataSaveService.SaveAll()`。 |
| **GameSceneManager.cs** | 游戏主场景入口：负责进入 GameScene 后显示主界面等默认 UI。 |

---

### Assets/Scripts/Game/Common

通用基础设施与跨模块服务，包含资源加载、资源路径、账号、本地保存、加密、货币与调试工具等。

| 脚本 | 功能 |
|------|------|
| **GameResourceLoader.cs** | 统一从 Resources 加载卡牌、道具、卡池、关卡等数据库资源。 |
| **GameResourcePaths.cs** | 集中维护 Resources 内数据库资源路径常量。 |

#### Game/Common/Auth

账号服务模块，负责本地注册、登录、记住密码与当前登录账号状态。

| 脚本 | 功能 |
|------|------|
| **AccountStore.cs** | 本地账号库：共享保存到 `persistentDataPath/UserData/account.dat`；登录/登出时清空玩家进度缓存，账号库读取失败时阻止覆盖原文件。 |

#### Game/Common/Currency

玩家货币服务模块，负责金币、钻石、船票的持久化与增减。

| 脚本 | 功能 |
|------|------|
| **CurrencyStore.cs** | 资源存储服务：按当前账号目录隔离 `currency.dat`，读档失败或账号不匹配时禁止保存，避免串档和覆盖损坏存档。 |

#### Game/Common/Save

本地保存协调与路径工具模块。

| 脚本 | 功能 |
|------|------|
| **GameDataSaveService.cs** | 统一保存服务：仅在已登录账号下保存货币、背包、卡牌仓库与编队，未登录时跳过玩家进度保存。 |
| **LocalUserDataPaths.cs** | 本地用户数据路径工具：生成共享账号库路径、当前账号哈希目录路径，并提供早期共享进度文件迁移路径。 |

#### Game/Common/Security

本地数据安全模块，负责存档文件加密与解密。

| 脚本 | 功能 |
|------|------|
| **LocalDataCrypto.cs** | 本地数据加密工具：将 JSON 文本加密为二进制并支持解密读取。 |

---

### Assets/Scripts/Game/Card/Application

卡牌应用服务层，负责玩家卡牌仓库、抽卡建造与编队数据。

| 脚本 | 功能 |
|------|------|
| **BuildService.cs** | 建造服务：校验并扣资源、按卡池权重抽卡、写入卡牌仓库；卡牌仓库不可写时不会扣资源，写入失败会回滚本次资源消耗。 |
| **CardCollectionStore.cs** | 卡牌仓库存储：按当前账号目录隔离 `card_collection.dat`，读档失败或切号缓存不一致时阻止覆盖保存。 |
| **FleetStore.cs** | 编队存储：按当前账号目录隔离 `fleet_data.dat`，维护多套卡组并在首次无编队文件时从卡牌仓库生成默认卡组。 |

### Assets/Scripts/Game/Card/Domain

卡牌与卡池领域配置层，使用 ScriptableObject 表达静态数据。

| 脚本 | 功能 |
|------|------|
| **BuildPoolConfigSO.cs** | 单个建造卡池配置：卡池 id、名称、消耗、阵营筛选与掉落权重。 |
| **BuildPoolDatabaseSO.cs** | 卡池数据库：集中保存全部可用建造卡池。 |
| **CardConfigDatabaseSO.cs** | 卡牌配置数据库：集中保存全部卡牌配置。 |
| **CardConfigSO.cs** | 单张卡牌配置：卡牌 id、名称、阵营、稀有度与表现数据等。 |
| **ShipFaction.cs** | 舰船阵营枚举，用于卡牌与卡池筛选。 |

---

### Assets/Scripts/Game/Inventory/Application

背包应用服务层，负责玩家道具数据的本地读写与增减。

| 脚本 | 功能 |
|------|------|
| **InventoryStore.cs** | 背包存储服务：按当前账号目录隔离 `inventory.dat`，提供增加、消耗、删除道具接口，并阻止读档失败后的覆盖保存。 |

### Assets/Scripts/Game/Inventory/Domain

道具领域配置层，定义道具静态数据与数据库。

| 脚本 | 功能 |
|------|------|
| **ItemConfigDatabaseSO.cs** | 道具配置数据库：集中保存全部道具配置。 |
| **ItemConfigSO.cs** | 单个道具配置：道具 id、名称、描述、图标与稀有度等。 |

---

### Assets/Scripts/Game/Level/Domain

关卡领域配置层，定义区域、关卡阶段与关卡数据库。

| 脚本 | 功能 |
|------|------|
| **LevelAreaConfigSO.cs** | 关卡区域配置：区域 id、名称、描述、图标与关卡阶段列表。 |
| **LevelAreaDatabaseSO.cs** | 关卡区域数据库：集中保存全部关卡区域配置。 |
| **LevelStageConfigSO.cs** | 单个关卡阶段配置：阶段 id、名称、描述、推荐等级与消耗等。 |

---

### Assets/Scripts/Game/UI/Presentation

UI 表现层基础设施与具体面板，负责面板生命周期、按钮交互、列表渲染与场景 UI 默认入口。

| 脚本 | 功能 |
|------|------|
| **BasePanel.cs** | 面板基类：提供显示、隐藏与面板名称基础能力。 |
| **PanelNames.cs** | 面板名称常量集合，避免字符串散落在各 UI 脚本中。 |
| **UIPanelRegistry.cs** | UI 面板注册与导航中心：管理面板栈、默认面板、场景切换与退出游戏。 |

#### Game/UI/Presentation/TitleScene

标题场景 UI，负责登录、注册、登出与进入游戏。

| 脚本 | 功能 |
|------|------|
| **LoginPanel.cs** | 登录/注册面板：调用 `AccountStore` 完成注册登录，登录成功后进入 GameScene。 |
| **TitlePanel.cs** | 标题面板：进入登录面板、退出账号、设置占位与退出游戏。 |

#### Game/UI/Presentation/GameScene

游戏主场景 UI，负责主界面导航、活动入口、背包、建造、船坞、编队与关卡选择。

| 脚本 | 功能 |
|------|------|
| **ActivityPanel.cs** | 活动面板占位入口。 |
| **BuildPanel.cs** | 建造面板：展示卡池并调用 `BuildService.TryBuild()`。 |
| **BuildPoolButtonView.cs** | 卡池按钮视图：绑定单个卡池简要信息。 |
| **BuildPoolDetailView.cs** | 卡池详情视图：显示卡池消耗、说明与掉落信息。 |
| **CardRevealEntryView.cs** | 抽卡结果单项视图：显示单张获得卡牌。 |
| **CardRevealPanel.cs** | 抽卡结果面板：展示本次建造获得的卡牌列表。 |
| **FleetCardSlotView.cs** | 编队卡槽视图：展示编队内单张卡牌。 |
| **FleetPanel.cs** | 编队面板：读取 `FleetStore` 与 `CardCollectionStore` 展示和维护卡组。 |
| **InventoryPanel.cs** | 背包面板：读取 `InventoryStore` 与道具配置展示道具列表。 |
| **InventorySlotView.cs** | 背包格子视图：绑定单个道具数量与显示信息。 |
| **LevelAreaInfoCardView.cs** | 关卡区域信息卡：展示区域概要。 |
| **LevelAreaSelectPanel.cs** | 关卡区域选择面板：展示全部区域并进入阶段选择。 |
| **LevelSelectPanel.cs** | 关卡选择入口面板：管理关卡选择流程入口。 |
| **LevelStageSelectPanel.cs** | 关卡阶段选择面板：展示区域内阶段，当前点击阶段只记录日志。 |
| **MainPanel.cs** | 主界面：显示玩家资源并导航到背包、建造、船坞、编队、关卡等面板。 |
| **ShipyardCardSlotView.cs** | 船坞卡牌格子视图：展示玩家拥有的单张卡牌。 |
| **ShipyardLazyVerticalList.cs** | 船坞懒加载列表：按可视区域复用卡牌格子。 |
| **ShipyardPanel.cs** | 船坞面板：读取卡牌仓库与卡牌配置展示舰娘列表。 |
