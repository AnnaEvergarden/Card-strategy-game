# 脚本结构图

> 本文档随 `Assets/Scripts/` 下脚本的增改而更新，用于快速查看当前重制版脚本分层、目录职责与关键脚本功能。

## 分层概览

```
启动/场景层
  Game/Bootstrap/Presentation
        ↓
UI 表现层
  Game/UI/Presentation
        ↓
应用服务层
  Game/Card/Application
  Game/Inventory/Application
  Game/Common/Save
        ↓
领域配置层
  Game/Card/Domain
  Game/Inventory/Domain
  Game/Level/Domain
        ↓
基础设施层
  Game/Common/Auth
  Game/Common/Currency
  Game/Common/Security
  Game/Common/Resources
```

- **启动/场景层**：负责游戏入口、场景切换生命周期与退出/后台自动保存。
- **UI 表现层**：负责面板注册、按钮事件、列表显示和用户交互，不直接保存底层文件。
- **应用服务层**：承接 UI 用例，处理建造、卡牌仓库、编队、背包和统一保存。
- **领域配置层**：ScriptableObject 配置与只读数据结构，描述卡牌、卡池、道具和关卡。
- **基础设施层**：负责账号、货币、本地路径、资源加载和加密读写等跨模块能力。

## 目录与脚本说明

### Assets/Scripts/Game/Bootstrap

启动和场景生命周期入口。

| 脚本 | 功能 |
|------|------|
| **Presentation/GameBootstrap.cs** | 游戏启动器；运行时强制回到标题场景，并在退出/切后台时调用 `GameDataSaveService.SaveAll()` 保存当前登录账号进度。 |
| **Presentation/GameSceneManager.cs** | GameScene 场景入口；负责初始化或显示游戏主界面相关面板。 |

### Assets/Scripts/Game/Common

跨系统基础能力，包括账号、货币、路径、资源和加密。

| 脚本 | 功能 |
|------|------|
| **Auth/AccountStore.cs** | 本地账号服务；注册、登录、登出、记住密码，账号库保存到持久化 `UserData/account.dat`，并可读取旧版共享账号库迁移。 |
| **Currency/CurrencyStore.cs** | 资源存储服务；按当前账号目录保存金币、钻石、船票，并用缓存归属键阻止切号后旧缓存写入。 |
| **Save/GameDataSaveService.cs** | 统一保存入口；未登录时跳过玩家进度保存，避免旧缓存覆盖账号数据。 |
| **Save/LocalUserDataPaths.cs** | 本地用户数据路径工具；共享账号库与按账号哈希隔离的玩家进度路径由这里统一生成。 |
| **Security/LocalDataCrypto.cs** | 本地 AES 加解密工具；为账号、货币、背包、卡牌仓库和编队文件提供加密/解密。 |
| **GameResourceLoader.cs** | Resources 加载门面；统一加载卡牌、卡池、道具、关卡等数据库资源。 |
| **GameResourcePaths.cs** | Resources 路径常量；集中管理数据库资源路径字符串。 |

### Assets/Scripts/Game/Card

卡牌配置、建造抽卡、卡牌仓库和编队数据。

#### Card/Application

| 脚本 | 功能 |
|------|------|
| **BuildService.cs** | 建造服务；校验并扣资源、按卡池权重抽卡、写入卡牌仓库；仓库写入失败时回滚已入库卡牌与资源。 |
| **CardCollectionStore.cs** | 卡牌仓库存储；按当前账号目录加密保存拥有卡牌，并阻止未登录、切号或读档失败后的自动写入。 |
| **FleetStore.cs** | 编队存储；按当前账号目录加密保存多套卡组，首次无编队文件时可从当前账号卡牌仓库生成默认编队。 |

#### Card/Domain

| 脚本 | 功能 |
|------|------|
| **CardConfigSO.cs** | 单张卡牌配置；包含 id、显示名、阵营、稀有度、图片、描述等基础数据。 |
| **CardConfigDatabaseSO.cs** | 卡牌配置数据库；集中持有所有 `CardConfigSO`。 |
| **BuildPoolConfigSO.cs** | 单个建造卡池配置；包含消耗、阵营过滤和权重掉落项。 |
| **BuildPoolDatabaseSO.cs** | 建造卡池数据库；集中持有所有卡池配置。 |
| **ShipFaction.cs** | 舰船阵营枚举。 |

### Assets/Scripts/Game/Inventory

道具背包配置与玩家背包持久化。

| 脚本 | 功能 |
|------|------|
| **Application/InventoryStore.cs** | 背包存储；按当前账号目录加密保存道具列表，并阻止旧缓存跨账号写入。 |
| **Domain/ItemConfigSO.cs** | 单个道具配置；定义道具 id、名称、描述、图标等。 |
| **Domain/ItemConfigDatabaseSO.cs** | 道具配置数据库；集中持有所有 `ItemConfigSO`。 |

### Assets/Scripts/Game/Level

关卡和章节配置数据。

| 脚本 | 功能 |
|------|------|
| **Domain/LevelAreaConfigSO.cs** | 章节/区域配置；描述区域名称、背景、关卡列表等。 |
| **Domain/LevelAreaDatabaseSO.cs** | 区域配置数据库；集中持有所有区域配置。 |
| **Domain/LevelStageConfigSO.cs** | 单个关卡配置；描述关卡 id、名称、消耗、奖励等。 |

### Assets/Scripts/Game/UI

面板、列表项和 UI 注册表。

#### UI/Presentation

| 脚本 | 功能 |
|------|------|

| **PanelNames.cs** | 面板名与场景名常量。 |
| **UIPanelRegistry.cs** | 面板注册表；负责面板显示、返回栈、场景加载，并在切场景前保存数据。 |

#### UI/Presentation/TitleScene

| 脚本 | 功能 |
|------|------|

| **LoginPanel.cs** | 登录面板；处理账号输入、注册、登录、记住密码和进入 GameScene。 |

| **ShipyardLazyVerticalList.cs** | 船坞懒加载列表；按滚动位置复用条目显示大量卡牌。 |

| **InventoryPanel.cs** | 背包面板；读取并展示当前账号道具列表。 |
| **InventorySlotView.cs** | 背包格；绑定道具数据与配置显示。 |

| **LevelAreaSelectPanel.cs** | 章节选择面板；展示章节卡片并处理拖拽切换。 |
| **LevelAreaInfoCardView.cs** | 章节信息卡；显示章节名称、背景和关卡摘要。 |
