# 脚本结构图

> 本文档随 `Assets/Scripts/` 下脚本的增改而更新，用于快速查看当前重制版工程的分层、目录职责与脚本职责。

## 分层概览

```text
启动/场景层       Game/Bootstrap/Presentation
                     ↓
应用服务层         Game/Common/Save, Game/Common/Auth, Game/Common/Currency
                 Game/Inventory/Application, Game/Card/Application
                     ↓
领域配置层         Game/Card/Domain, Game/Inventory/Domain, Game/Level/Domain
                     ↓
表现/UI 层         Game/UI/Presentation
                     ↓
调试/工具层        Game/Debug, Game/Core
```

- **启动/场景层**：负责从标题场景进入、切换场景与应用退出/暂停时触发保存。
- **应用服务层**：负责账号、本地路径、加密存档、资源、背包、卡牌仓库、建造与编队等可变游戏进度。
- **领域配置层**：使用 ScriptableObject 或 JSON 加载卡牌、道具、关卡区域与关卡节点等静态配置。
- **表现/UI 层**：负责标题、登录、主界面、建造、船坞、仓库、编队、关卡选择等界面展示与按钮入口。
- **调试/工具层**：提供编辑器资产重命名、UI 射线调试等辅助能力。

## 目录与脚本说明

### Assets/Scripts/

项目 C# 脚本根目录，当前主要按 `Game` 目录内的功能域与分层组织。

### Assets/Scripts/Game/

重制版游戏脚本根目录，按 Bootstrap、Common、Card、Inventory、Level、UI、Debug、Core 等子域拆分。

---

### Game/Bootstrap/Presentation

启动与场景编排层，负责应用入口、强制进入标题场景与游戏场景加载。

| 脚本 | 功能 |
|------|------|
| **GameBootstrap.cs** | 游戏启动器：保持全局对象、从任意场景运行时回到标题场景，并在退出/暂停时调用统一保存。 |
| **GameSceneManager.cs** | 游戏场景管理入口：处理游戏场景内需要的初始化与界面入口。 |

---

### Game/Common

跨系统公共能力，包括资源路径、资源加载、账号、本地安全与存档服务。

| 脚本 | 功能 |
|------|------|
| **GameResourceLoader.cs** | 封装 Resources 加载入口，集中处理资源读取。 |
| **GameResourcePaths.cs** | 维护 Resources 下常用资源路径常量。 |

#### Game/Common/Auth

账号服务层，负责本地账号注册、登录、记住密码与当前登录账号状态。

| 脚本 | 功能 |
|------|------|
| **AccountStore.cs** | 本地账号库：读写共享 `account.dat`，提供注册、登录、登出、记住密码与当前账号查询。 |

#### Game/Common/Currency

资源服务层，负责金币、钻石、船票等数值资源的持久化与安全增减。

| 脚本 | 功能 |
|------|------|
| **CurrencyStore.cs** | 玩家资源仓库：按当前登录账号隔离读写 `currency.dat`，提供 Load、SaveCurrent、TryConsume、Add。 |

#### Game/Common/Save

本地存档服务层，负责统一保存和账号隔离路径。

| 脚本 | 功能 |
|------|------|
| **GameDataSaveService.cs** | 退出/暂停时统一保存资源、背包、卡牌仓库和编队；未登录时跳过进度保存。 |
| **LocalUserDataPaths.cs** | 本地用户数据路径工具：账号库使用共享路径，玩家进度按登录账号哈希目录隔离，并支持旧共享进度首次迁移。 |

#### Game/Common/Security

本地数据安全层，负责存档明文 JSON 的加密与解密。

| 脚本 | 功能 |
|------|------|
| **LocalDataCrypto.cs** | AES-CBC 加解密工具：用项目种子与设备标识派生密钥，处理 UserData 下的加密 JSON。 |

---

### Game/Card/Application

卡牌应用服务层，负责建造抽卡、卡牌仓库与编队等玩家可变数据。

| 脚本 | 功能 |
|------|------|
| **BuildService.cs** | 建造服务：根据卡池消耗资源并产出卡牌，写入卡牌仓库。 |
| **CardCollectionStore.cs** | 卡牌仓库存储：按当前登录账号隔离读写 `card_collection.dat`，支持增加、消耗、删除卡牌。 |
| **FleetStore.cs** | 编队存储：按当前登录账号隔离读写 `fleet_data.dat`，维护多套最多 6 张卡牌的卡组。 |

### Game/Card/Domain

卡牌领域配置层，负责卡牌基础属性、阵营、建造卡池与卡牌配置数据库。

| 脚本 | 功能 |
|------|------|
| **BuildPoolConfigSO.cs** | 单个建造卡池配置：卡池名称、消耗、可产出卡牌与概率等。 |
| **BuildPoolDatabaseSO.cs** | 建造卡池数据库：集中引用多个卡池配置供 UI 与服务查询。 |
| **CardConfigDatabaseSO.cs** | 卡牌配置数据库：集中引用 CardConfigSO，提供卡牌配置查找来源。 |
| **CardConfigSO.cs** | 单张卡牌配置：维护 ID、名称、稀有度、阵营、图标与基础展示数据。 |
| **ShipFaction.cs** | 舰船阵营枚举：描述卡牌所属阵营。 |

---

### Game/Inventory/Application

背包应用服务层，负责玩家道具数量的持久化与增减。

| 脚本 | 功能 |
|------|------|
| **InventoryStore.cs** | 道具仓库存储：按当前登录账号隔离读写 `inventory.dat`，支持增加、消耗、删除道具。 |

### Game/Inventory/Domain

背包领域配置层，负责道具静态配置与配置数据库。

| 脚本 | 功能 |
|------|------|
| **ItemConfigDatabaseSO.cs** | 道具配置数据库：集中引用 ItemConfigSO 供仓库 UI 查询。 |
| **ItemConfigSO.cs** | 单个道具配置：维护道具 ID、显示名、图标与描述等静态信息。 |

---

### Game/Level/Domain

关卡领域配置层，负责章节区域、关卡节点与关卡数据库。

| 脚本 | 功能 |
|------|------|
| **LevelAreaConfigSO.cs** | 单个关卡区域配置：维护区域名称、描述、背景与关卡列表。 |
| **LevelAreaDatabaseSO.cs** | 关卡区域数据库：集中引用多个区域配置供关卡选择界面使用。 |
| **LevelStageConfigSO.cs** | 单个关卡节点配置：维护关卡名称、编号、推荐信息与奖励等。 |

### Game/UI/Presentation

UI 表现层根目录，包含面板基类、面板注册表、面板名与各场景界面。

| 脚本 | 功能 |
|------|------|
| **BasePanel.cs** | UI 面板基类：封装面板显示/隐藏与注册表协作。 |
| **PanelNames.cs** | 面板名与场景名常量：避免界面跳转使用散落字符串。 |
| **UIPanelRegistry.cs** | UI 面板注册与导航：管理 Push、Pop、场景加载和退出游戏时的保存。 |

#### Game/UI/Presentation/TitleScene

| 脚本 | 功能 |
|------|------|

| **TitlePanel.cs** | 标题面板：处理打开登录面板、退出账号、设置占位与退出游戏。 |
