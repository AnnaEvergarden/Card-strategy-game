# 脚本结构图

> 本文档随 `Assets/Scripts/` 下脚本的增改而更新，用于快速查看当前重制版分层、目录职责与关键脚本。

## 分层概览

```
Bootstrap/Presentation        GameBootstrap, GameSceneManager
        ↓
Common                        Auth / Currency / Save / Security / Resources
        ↓
Game Domain/Application       Card, Inventory, Level
        ↓
UI/Presentation               UIPanelRegistry, BasePanel, TitleScene, GameScene
        ↓
Debug/Core                    调试工具与编辑器资产重命名工具
```

- **Bootstrap/Presentation**：场景启动与全局生命周期，负责从入口场景进入标题场景，并在退出/切后台时触发统一保存。
- **Common**：跨系统基础能力，包括账号、货币、本地加密、资源路径、资源加载和统一保存。
- **Game Domain/Application**：卡牌、建造、舰队、背包、关卡等领域配置与应用层持久化服务。
- **UI/Presentation**：标题、登录、主界面、建造、背包、船坞、编队、关卡选择等面板和面板栈注册。
- **Debug/Core**：调试热键与编辑器辅助工具，不参与核心运行时流程。

## 目录与脚本说明

### Assets/Scripts/

项目 C# 脚本根目录，当前按 `Game` 子目录组织，并继续区分启动、公共基础设施、领域/应用与 UI 表现层。

---

### Game/Bootstrap/Presentation

场景入口与启动流程。

| 脚本 | 功能 |
|------|------|
| **GameBootstrap.cs** | 运行时启动器；确保从标题场景进入，并在退出/切后台时调用 `GameDataSaveService.SaveAll()`。 |
| **GameSceneManager.cs** | GameScene 入口；确保各游戏内面板注册到 `UIPanelRegistry` 并建立默认面板栈。 |

---

### Game/Common

跨模块公共能力：资源路径、资源加载、本地账号、货币、保存服务与本地加密。

| 脚本 | 功能 |
|------|------|
| **GameResourcePaths.cs** | 集中定义 `Resources.Load` 使用的数据库路径常量。 |
| **GameResourceLoader.cs** | 加载卡牌、建造、道具、关卡等 ScriptableObject 数据库。 |
| **Auth/AccountStore.cs** | 本地账号注册、登录、登出、记住密码与当前账号状态。 |
| **Currency/CurrencyStore.cs** | 货币数据加密持久化；自动保存前先加载可信缓存，加载失败时阻止覆盖原文件。 |
| **Save/GameDataSaveService.cs** | 统一保存入口；退出/切后台时保存账号外的关键本地进度。 |
| **Security/LocalDataCrypto.cs** | 本地数据 AES 加解密与密钥派生。 |

---

### Game/Card

卡牌配置、建造抽卡、卡牌仓库与舰队编成数据。

#### Game/Card/Domain

| 脚本 | 功能 |
|------|------|
| **CardConfigSO.cs** | 单张卡牌配置：ID、显示名、阵营、稀有度、立绘与描述。 |
| **CardConfigDatabaseSO.cs** | 卡牌配置数据库，供 UI 和应用服务查找 `cardId`。 |
| **BuildPoolConfigSO.cs** | 建造卡池配置：卡池 ID、阵营、单抽/十连成本与掉落权重。 |
| **BuildPoolDatabaseSO.cs** | 建造卡池数据库。 |
| **ShipFaction.cs** | 舰船阵营枚举。 |

#### Game/Card/Application

| 脚本 | 功能 |
|------|------|
| **BuildService.cs** | 建造服务：扣资源、按权重抽卡并写入卡牌仓库。 |
| **CardCollectionStore.cs** | 卡牌仓库加密持久化；自动保存前先加载可信缓存，加载失败时阻止覆盖原文件。 |
| **FleetStore.cs** | 编队数据加密持久化；自动保存前先加载可信缓存，加载失败时阻止覆盖原文件。 |
