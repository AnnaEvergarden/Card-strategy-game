# 脚本结构图

> 本文档随 `Assets/Scripts/` 下脚本的增改而更新，用于快速查看分层与各脚本/文件夹职责。

## 分层概览

```
启动/场景层        Game/Bootstrap/Presentation
                    ↓
表现/UI 层         Game/UI/Presentation, Game/Debug
                    ↓
应用服务层         Game/Card/Application, Game/Inventory/Application, Game/Common/Save
                    ↓
领域配置层         Game/Card/Domain, Game/Inventory/Domain, Game/Level/Domain
                    ↓
公共基础设施层     Game/Common/Auth, Game/Common/Currency, Game/Common/Security, Game/Common/资源加载
                    ↓
编辑器辅助层       Game/Core
```

- **启动/场景层**：控制进入场景、全局启动对象以及应用退出/切后台保存。
- **表现/UI 层**：面板注册、导航和各场景面板展示；通过应用服务读取或提交数据。
- **应用服务层**：建造、卡牌仓库、编队、背包与统一保存等用户数据操作。
- **领域配置层**：ScriptableObject 配置和查表数据，承载卡牌、道具、关卡等静态规则。
- **公共基础设施层**：账号、本地路径、加密、资源和货币等横向能力。
- **编辑器辅助层**：仅服务编辑器资源整理与开发辅助。

## 目录与脚本说明

### Assets/Scripts/

项目 C# 脚本根目录，当前主要代码位于 `Game/` 下。

### Assets/Scripts/Game/

游戏主代码目录，按 Bootstrap、Common、Card、Inventory、Level、UI 等功能域组织。

---

### Game/Bootstrap

启动与场景入口相关逻辑。

#### Game/Bootstrap/Presentation

| 脚本 | 功能 |
|------|------|
| **GameBootstrap.cs** | 全局启动器：确保从标题场景进入，并在退出/切后台时调用 `GameDataSaveService.SaveAll()`。 |
| **GameSceneManager.cs** | 游戏场景入口辅助脚本，用于场景初始化或后续扩展场景级流程。 |

---

### Game/Common

跨模块公共能力：账号、货币、本地保存、加密与资源路径。

#### Game/Common/Auth

| 脚本 | 功能 |
|------|------|
| **AccountStore.cs** | 本地账号库：注册、登录、退出、记住密码与当前账号；账号库读取失败时阻止空库覆盖原文件。 |

#### Game/Common/Currency

| 脚本 | 功能 |
|------|------|
| **CurrencyStore.cs** | 当前账号货币数据（金币、钻石、船票）的加密读写与增减；读档失败时禁止覆盖原文件。 |

#### Game/Common/Save

| 脚本 | 功能 |
|------|------|
| **GameDataSaveService.cs** | 统一保存当前登录账号的货币、背包、卡牌仓库和编队；账号切换时清理运行时缓存。 |
| **LocalSavePath.cs** | 本地路径工具：使用 `Application.persistentDataPath`，并按账号生成隔离的进度目录。 |

#### Game/Common/Security

| 脚本 | 功能 |
|------|------|
| **LocalDataCrypto.cs** | 本地 JSON 数据 AES 加解密；使用稳定项目密钥，并兼容旧设备绑定密钥读取。 |

#### Game/Common（根目录）

| 脚本 | 功能 |
|------|------|
| **GameResourceLoader.cs** | 公共资源加载辅助，封装 Resources 等加载入口。 |
| **GameResourcePaths.cs** | 游戏资源路径常量集中定义，供 UI、配置加载等模块复用。 |

---

### Game/Card

卡牌、建造池、卡牌仓库与编队相关逻辑。

#### Game/Card/Application

| 脚本 | 功能 |
|------|------|
| **BuildService.cs** | 建造服务：扣除资源、按建造池抽取卡牌并写入 `CardCollectionStore`，失败时回滚资源。 |
| **CardCollectionStore.cs** | 当前账号卡牌仓库加密读写与增删改；读档失败时禁止覆盖原文件。 |
| **FleetStore.cs** | 当前账号编队加密读写与默认编队生成；读档失败时禁止覆盖原文件。 |

#### Game/Card/Domain

| 脚本 | 功能 |
|------|------|
| **BuildPoolConfigSO.cs** | 单个建造池配置（消耗、权重、可获得卡牌等）。 |
| **BuildPoolDatabaseSO.cs** | 建造池配置数据库，用于查找和枚举建造池。 |
| **CardConfigDatabaseSO.cs** | 卡牌配置数据库，按 cardId 查找 `CardConfigSO`。 |
| **CardConfigSO.cs** | 单张卡牌的静态配置（名称、阵营、稀有度、图标等）。 |
| **ShipFaction.cs** | 舰船/卡牌阵营枚举。 |

---

### Game/Inventory

#### Game/Inventory/Application

| 脚本 | 功能 |
|------|------|
| **InventoryStore.cs** | 当前账号道具背包加密读写与增删消耗；读档失败时禁止覆盖原文件。 |

#### Game/Inventory/Domain

| 脚本 | 功能 |
|------|------|
| **ItemConfigDatabaseSO.cs** | 道具配置数据库，按 itemId 查找道具配置。 |
| **ItemConfigSO.cs** | 单个道具配置（名称、图标、描述等）。 |

### Game/Level

关卡区域和关卡配置。

#### Game/Level/Domain

| 脚本 | 功能 |
|------|------|

| **LevelAreaDatabaseSO.cs** | 关卡区域数据库，供选关 UI 枚举区域。 |

### Game/UI

所有运行时 UI 面板、面板注册与导航。

#### Game/UI/Presentation

| 脚本 | 功能 |
|------|------|
| **BasePanel.cs** | UI 面板基类，负责面板名、注册和显隐基础行为。 |
| **PanelNames.cs** | 面板名与场景名常量，统一 UI 导航字符串。 |
| **UIPanelRegistry.cs** | 静态面板注册表与面板栈：Push/Pop/ClearAndPush、换场景默认根面板等。 |

#### Game/UI/Presentation/TitleScene

| 脚本 | 功能 |
|------|------|
| **TitlePanel.cs** | 标题页入口：登录、退出账号、设置占位和退出游戏；退出账号前保存并清理缓存。 |
| **LoginPanel.cs** | 登录/注册界面：登录成功后清理旧账号缓存、保存记住密码并进入游戏场景。 |

#### Game/UI/Presentation/GameScene

| 脚本 | 功能 |
|------|------|
| **MainPanel.cs** | 游戏主界面：展示货币与入口按钮，读取 `CurrencyStore` 刷新资源。 |
| **ActivityPanel.cs** | 活动面板占位与展示入口。 |
| **BuildPanel.cs** | 建造面板：展示建造池、发起建造、展示抽取结果。 |
| **BuildPoolButtonView.cs** | 单个建造池按钮视图，绑定建造池名称和点击回调。 |
| **BuildPoolDetailView.cs** | 建造池详情视图，显示消耗、说明和可能产出等信息。 |
| **CardRevealEntryView.cs** | 抽卡结果单项视图。 |
| **CardRevealPanel.cs** | 抽卡/建造结果面板，批量展示获得的卡牌。 |
| **FleetPanel.cs** | 编队面板：读取 `FleetStore` 和卡牌配置，展示并调整卡组。 |
| **FleetCardSlotView.cs** | 编队槽位视图，显示单个编队卡牌位置。 |
| **InventoryPanel.cs** | 背包面板：读取 `InventoryStore` 和道具配置展示道具列表。 |
| **InventorySlotView.cs** | 背包单格视图，绑定道具数量、图标和名称。 |
| **LevelSelectPanel.cs** | 关卡选择入口面板，进入区域选择。 |
| **LevelAreaSelectPanel.cs** | 关卡区域选择面板，展示区域卡片并进入关卡列表。 |
| **LevelAreaInfoCardView.cs** | 区域信息卡片视图，绑定区域名称、描述和按钮。 |
| **LevelStageSelectPanel.cs** | 区域内关卡选择面板，展示关卡并记录点击选择。 |
| **ShipyardPanel.cs** | 船坞面板：读取 `CardCollectionStore` 展示玩家持有卡牌。 |
| **ShipyardLazyVerticalList.cs** | 船坞懒加载列表，按滚动位置复用卡牌槽位。 |
| **ShipyardCardSlotView.cs** | 船坞卡牌槽位视图，绑定卡牌配置、数量和稀有度显示。 |
