# 脚本结构图

> 本文档随 `Assets/Scripts/` 下脚本的增改而更新，用于快速查看分层与各脚本/文件夹职责。

## 分层概览

```
启动/场景层        Game/Bootstrap/Presentation
                       ↓
应用服务层          Game/Card/Application, Game/Inventory/Application, Game/Common/*Store
                       ↓
领域配置层          Game/Card/Domain, Game/Inventory/Domain, Game/Level/Domain
                       ↑
表现层 UI           Game/UI/Presentation（TitleScene, GameScene, BasePanel, UIPanelRegistry）
                       ↓
通用基础设施        Game/Common（资源路径、加载器、存档路径、加密、安全）
                       ↓
调试/编辑器工具      Game/Debug, Game/Core
```

- **启动/场景层**：负责从标题场景进入、切换主要场景，以及退出/后台时触发保存。
- **应用服务层**：承载玩家进度读写、建造抽卡、卡牌收藏、编队、货币与仓库等可变数据逻辑。
- **领域配置层**：用 ScriptableObject 描述卡牌、卡池、道具与关卡等静态配置，不直接操作 UI。
- **表现层 UI**：BasePanel 与 UIPanelRegistry 管理面板显隐和栈式导航；具体面板调用应用服务层。
- **通用基础设施**：集中资源路径、Resources 加载、本地数据加密、账号隔离存档路径等横切能力。
- **调试/编辑器工具**：运行时调试热键与编辑器资源命名工具，不参与核心业务流程。

## 目录与脚本说明

### Assets/Scripts/

项目 C# 脚本根目录；当前重制版主要集中在 `Game/` 目录，并按 Bootstrap、Common、Card、Inventory、Level、UI 等模块分层。

---

### Game/Bootstrap/Presentation

启动与场景入口层，负责进入正确场景和统一场景常量。

| 脚本 | 功能 |
|------|------|
| **GameBootstrap.cs** | 游戏启动器：运行时强制从标题场景进入，并在退出或切后台时调用统一保存服务。 |
| **GameSceneManager.cs** | 场景名常量定义，供登录、UI 导航和启动流程统一引用。 |

---

### Game/Common

通用基础设施目录，提供资源加载、存档、账号、货币、安全等跨模块服务。

| 脚本 | 功能 |
|------|------|
| **GameResourceLoader.cs** | Resources 资源加载封装：读取卡牌、道具、关卡、卡池数据库等 ScriptableObject。 |
| **GameResourcePaths.cs** | Resources 路径常量表，统一维护数据库资源路径。 |

#### Game/Common/Auth

账号相关服务，负责本地注册、登录和记住密码状态。

| 脚本 | 功能 |
|------|------|
| **AccountStore.cs** | 本地账号存储：维护账号列表、当前登录账号、记住密码配置，并加密保存到 `account.dat`。 |

#### Game/Common/Currency

玩家资源数据服务。

| 脚本 | 功能 |
|------|------|
| **CurrencyStore.cs** | 玩家金币、钻石、船票的加载、保存、增加和消耗；进度文件按当前账号隔离。 |

#### Game/Common/Save

统一保存与玩家进度路径辅助。

| 脚本 | 功能 |
|------|------|
| **GameDataSaveService.cs** | 退出或切后台时保存已加载的关键本地数据。 |
| **PlayerDataPath.cs** | 玩家进度路径辅助：按当前账号生成货币、背包、卡牌仓库和编队文件路径，并迁移旧版全局文件。 |

#### Game/Common/Security

本地数据加密能力。

| 脚本 | 功能 |
|------|------|
| **LocalDataCrypto.cs** | AES 加解密工具：将本地 JSON 数据加密为二进制文件并解密恢复。 |

---

### Game/Card

卡牌、卡池、建造和编队模块。

#### Game/Card/Domain

卡牌与卡池静态配置。

| 脚本 | 功能 |
|------|------|
| **BuildPoolConfigSO.cs** | 单个建造卡池配置：卡池 ID、显示信息、消耗、掉落条目和权重。 |
| **BuildPoolDatabaseSO.cs** | 卡池数据库：集中持有全部 BuildPoolConfigSO。 |
| **CardConfigDatabaseSO.cs** | 卡牌配置数据库：集中持有全部 CardConfigSO，并提供按 ID 查找。 |
| **CardConfigSO.cs** | 单张卡牌静态配置：ID、名称、稀有度、阵营、描述、立绘/图标等。 |
| **ShipFaction.cs** | 舰船阵营枚举，供卡牌与卡池筛选使用。 |

#### Game/Card/Application

卡牌相关应用服务与玩家可变数据。

| 脚本 | 功能 |
|------|------|
| **BuildService.cs** | 建造服务：校验并扣除资源，按卡池权重抽卡，然后写入玩家卡牌仓库。 |
| **CardCollectionStore.cs** | 玩家卡牌仓库：记录 cardId 与数量，进度文件按当前账号隔离。 |
| **FleetStore.cs** | 玩家编队数据：维护多套卡组与每组卡牌 ID，进度文件按当前账号隔离。 |

### Game/Inventory

#### Game/Inventory/Domain

道具静态配置。

| 脚本 | 功能 |
|------|------|
| **ItemConfigDatabaseSO.cs** | 道具配置数据库：集中持有全部 ItemConfigSO，并提供按 ID 查找。 |
| **ItemConfigSO.cs** | 单个道具配置：ID、名称、图标、描述、稀有度等展示信息。 |

#### Game/Inventory/Application

玩家背包可变数据。

| 脚本 | 功能 |
|------|------|
| **InventoryStore.cs** | 玩家道具仓库：增加、消耗、移除道具，并按当前账号隔离保存。 |

### Game/Level/Domain

关卡区域与关卡条目配置。

| 脚本 | 功能 |
|------|------|
| **LevelAreaConfigSO.cs** | 关卡区域配置：区域 ID、名称、背景、所属关卡列表等。 |
| **LevelAreaDatabaseSO.cs** | 关卡区域数据库：集中持有全部 LevelAreaConfigSO。 |
| **LevelStageConfigSO.cs** | 单个关卡配置：关卡 ID、区域 ID、显示名、排序与描述等。 |

### Game/UI/Presentation

UI 表现层基础设施与面板实现。

| 脚本 | 功能 |
|------|------|
| **BasePanel.cs** | 面板基类：提供 PanelName、Show/Hide 和注册到 UIPanelRegistry 的生命周期。 |
| **PanelNames.cs** | UI 面板名称常量，避免 Push/Show 时手写字符串。 |
| **UIPanelRegistry.cs** | 静态 UI 面板注册表：处理面板注册、栈式导航、场景默认面板、退出游戏保存。 |

#### Game/UI/Presentation/TitleScene

标题与登录流程 UI。

| 脚本 | 功能 |
|------|------|
| **TitlePanel.cs** | 标题面板：登录入口、登出当前账号、设置占位、退出游戏。 |
| **LoginPanel.cs** | 登录面板：账号输入、注册、登录、记住密码和进入游戏场景。 |

#### Game/UI/Presentation/GameScene

主游戏场景内各功能面板与列表项。

| 脚本 | 功能 |
|------|------|
| **ActivityPanel.cs** | 活动面板占位：展示活动入口并提供返回。 |
| **BuildPanel.cs** | 建造面板：展示卡池、切换卡池详情、执行单抽/十连并打开揭示面板。 |
| **BuildPoolButtonView.cs** | 卡池按钮视图：绑定卡池名称、选中状态和点击回调。 |
| **BuildPoolDetailView.cs** | 卡池详情视图：展示卡池说明、消耗与掉落预览。 |
| **CardRevealEntryView.cs** | 单张抽卡结果视图：展示抽到的卡牌信息。 |
| **CardRevealPanel.cs** | 抽卡揭示面板：展示建造结果列表并支持返回。 |
| **FleetCardSlotView.cs** | 编队卡牌槽位视图：展示编队中的卡牌与槽位序号。 |
| **FleetPanel.cs** | 编队面板：加载编队和卡牌配置，展示当前卡组与卡牌条目。 |
| **InventoryPanel.cs** | 仓库面板：加载玩家道具和道具配置，生成道具列表。 |
| **InventorySlotView.cs** | 仓库格子视图：绑定单个道具数量和配置展示。 |
| **LevelAreaInfoCardView.cs** | 关卡区域信息卡：展示区域详情与进入区域按钮。 |
| **LevelAreaSelectPanel.cs** | 关卡区域选择面板：横向浏览区域并进入关卡列表。 |
| **LevelSelectPanel.cs** | 关卡类型选择面板：进入常驻或活动关卡入口。 |
| **LevelStageSelectPanel.cs** | 区域关卡列表面板：展示当前区域的关卡条目与返回。 |
| **MainPanel.cs** | 游戏主界面：展示资源，进入战斗、仓库、船坞、编队、建造和活动。 |
| **ShipyardCardSlotView.cs** | 船坞卡牌槽视图：展示卡牌图标、稀有度、数量和选中状态。 |
| **ShipyardLazyVerticalList.cs** | 船坞懒加载列表：按可见区域复用卡牌槽位，降低大量卡牌时的 UI 开销。 |
| **ShipyardPanel.cs** | 船坞面板：加载玩家卡牌仓库与配置表，并驱动懒加载列表。 |
