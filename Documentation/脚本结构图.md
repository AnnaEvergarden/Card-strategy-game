# 脚本结构图

> 本文档随 `Assets/Scripts/` 下脚本的增改而更新，用于快速查看当前重制版的分层、目录职责与关键脚本职责。

## 分层概览

```
入口/启动层
└─ Game/Bootstrap/Presentation
   ├─ GameBootstrap：启动场景校正、退出/后台自动保存
   └─ GameSceneManager：游戏场景入口

应用/服务层
├─ Game/Common
│  ├─ Auth：账号注册、登录、当前账号状态
│  ├─ Currency：金币/钻石/船票存储与消费
│  ├─ Save：统一退出保存、账号隔离数据路径
│  ├─ Security：本地数据加解密
│  └─ GameResourceLoader/GameResourcePaths：Resources 资源加载
├─ Game/Card/Application：建造、卡牌仓库、编队持久化
└─ Game/Inventory/Application：背包持久化

领域配置层
├─ Game/Card/Domain：卡牌、阵营、卡池 ScriptableObject 配置
├─ Game/Inventory/Domain：道具 ScriptableObject 配置
└─ Game/Level/Domain：关卡区域与关卡 ScriptableObject 配置

表现/UI 层
└─ Game/UI/Presentation
   ├─ BasePanel、UIPanelRegistry、PanelNames：面板基类、面板栈、名称常量
   ├─ TitleScene：标题、登录面板
   └─ GameScene：主界面、建造、船坞、背包、编队、关卡选择等面板

调试/工具层
├─ Game/Debug：UI 射线调试热键
└─ Game/Core：编辑器资产重命名工具
```

- **入口/启动层**：负责运行时入口、场景校正和应用退出/后台切换时的保存触发，不承载具体领域规则。
- **应用/服务层**：负责本地账号、存档路径、加密读写、资源/背包/卡牌/编队等可变玩家数据；玩家进度通过 `LocalUserDataPaths` 按当前登录账号隔离。
- **领域配置层**：用 ScriptableObject 和枚举承载卡牌、卡池、道具、关卡等静态配置，供应用层和 UI 查询。
- **表现/UI 层**：负责面板注册、栈导航、展示与用户点击入口，通过应用/服务层读取或修改数据。
- **调试/工具层**：提供开发期辅助能力，不参与运行时核心流程。

## 目录与脚本说明

### Assets/Scripts/

项目 C# 脚本根目录，当前重制版主要代码位于 `Assets/Scripts/Game/`。

### Assets/Scripts/Game/

重制版游戏脚本根目录，按 Bootstrap、Common、Card、Inventory、Level、UI、Debug、Core 等职责切分。

#### Game/Bootstrap/Presentation/

启动与场景入口，依赖 Common 保存服务和 Unity 场景系统。

| 脚本 | 功能 |
|------|------|
| **GameBootstrap.cs** | 启动时强制回到标题场景；应用退出或切后台时调用 `GameDataSaveService.SaveAll()` 自动保存当前登录账号数据。 |
| **GameSceneManager.cs** | 游戏场景入口脚本，用于承接游戏场景初始化流程。 |

#### Game/Common/Auth/

本地账号库服务，负责注册、登录、登出、记住密码和当前账号状态。

| 脚本 | 功能 |
|------|------|
| **AccountStore.cs** | 账号库读写；账号库使用 `LocalUserDataPaths.GetSharedDataFilePath("account.dat")` 存在共享持久化目录。 |

#### Game/Common/Currency/

玩家货币与抽卡资源存储。

| 脚本 | 功能 |
|------|------|
| **CurrencyStore.cs** | 按当前登录账号读写 `currency.dat`，提供 `TryConsume` / `Add`；读档失败时禁止自动保存和资源变更，避免覆盖原存档。 |

#### Game/Common/Save/

统一存档服务和本地路径策略。

| 脚本 | 功能 |
|------|------|
| **GameDataSaveService.cs** | 退出/后台切换时统一保存资源、背包、卡牌仓库、编队；当前未登录账号时跳过进度保存。 |
| **LocalUserDataPaths.cs** | 统一生成持久化路径：账号库共享，玩家进度按账号名哈希目录隔离；支持一次性迁移可解密的旧共享进度文件。 |

#### Game/Common/Security/

本地数据加解密能力。

| 脚本 | 功能 |
|------|------|
| **LocalDataCrypto.cs** | 使用项目种子和设备 ID 派生 AES 密钥，负责本地 JSON 数据加密/解密。 |

#### Game/Common/

通用资源加载和路径常量。

| 脚本 | 功能 |
|------|------|
| **GameResourceLoader.cs** | 从 Resources 加载卡牌、道具、关卡、卡池等数据库资源。 |
| **GameResourcePaths.cs** | 集中定义 Resources 下的数据库路径常量。 |

#### Game/Card/Application/

卡牌相关应用服务，处理抽卡、玩家卡牌仓库和编队持久化。

| 脚本 | 功能 |
|------|------|
| **BuildService.cs** | 执行建造/抽卡：校验并扣资源、按卡池权重抽卡、写入卡牌仓库；卡牌仓库不可写时回滚本次资源消耗。 |
| **CardCollectionStore.cs** | 按当前登录账号读写 `card_collection.dat`；提供增加、消耗、删除卡牌接口；读档失败时阻止覆盖原存档。 |
| **FleetStore.cs** | 按当前登录账号读写 `fleet_data.dat`；维护多套卡组并限制单卡组最多 6 张，缺省时可从卡牌仓库生成默认编队。 |

#### Game/Card/Domain/

卡牌、卡池与阵营静态配置。

| 脚本 | 功能 |
|------|------|
| **CardConfigSO.cs** | 单张卡牌配置：ID、名称、稀有度、阵营、立绘/图标、描述等。 |
| **CardConfigDatabaseSO.cs** | 卡牌配置数据库，提供卡牌配置集合。 |
| **BuildPoolConfigSO.cs** | 单个建造卡池配置：消耗、阵营、掉落权重等。 |
| **BuildPoolDatabaseSO.cs** | 卡池配置数据库，提供卡池集合。 |
| **ShipFaction.cs** | 舰船/卡牌阵营枚举。 |

#### Game/Inventory/Application/

玩家道具背包持久化。

| 脚本 | 功能 |
|------|------|
| **InventoryStore.cs** | 按当前登录账号读写 `inventory.dat`；提供增加、消耗、删除道具接口；读档失败时阻止覆盖原存档。 |

#### Game/Inventory/Domain/

道具静态配置。

| 脚本 | 功能 |
|------|------|
| **ItemConfigSO.cs** | 单个道具配置：ID、名称、描述、图标等。 |
| **ItemConfigDatabaseSO.cs** | 道具配置数据库，提供道具配置集合。 |

#### Game/Level/Domain/

关卡区域和关卡静态配置。

| 脚本 | 功能 |
|------|------|
| **LevelAreaConfigSO.cs** | 关卡区域配置：区域 ID、名称、描述、背景、关卡列表等。 |
| **LevelAreaDatabaseSO.cs** | 关卡区域数据库。 |
| **LevelStageConfigSO.cs** | 单个关卡配置：关卡 ID、名称、描述、消耗、奖励等。 |

#### Game/UI/Presentation/

UI 面板基础设施和各场景面板表现。

| 脚本 | 功能 |
|------|------|
| **BasePanel.cs** | 面板基类，负责注册/注销到 `UIPanelRegistry` 并提供基础显隐能力。 |
| **UIPanelRegistry.cs** | 面板注册表与导航栈；负责 Push、Pop、ClearAndPush、换场景默认面板和退出游戏。 |
| **PanelNames.cs** | UI 面板名称和场景名称常量。 |

#### Game/UI/Presentation/TitleScene/

标题场景 UI。

| 脚本 | 功能 |
|------|------|
| **TitlePanel.cs** | 标题面板：登录入口、退出账号、设置占位、退出游戏。 |
| **LoginPanel.cs** | 登录面板：注册、登录、记住密码和登录后进入游戏场景。 |

#### Game/UI/Presentation/GameScene/

游戏主场景 UI，读取应用/服务层数据并渲染。

| 脚本 | 功能 |
|------|------|
| **MainPanel.cs** | 主界面面板，展示资源并作为功能入口。 |
| **BuildPanel.cs** | 建造面板，展示卡池并触发 `BuildService.TryBuild`。 |
| **BuildPoolButtonView.cs** | 卡池按钮视图。 |
| **BuildPoolDetailView.cs** | 卡池详情视图。 |
| **CardRevealPanel.cs** | 抽卡结果展示面板。 |
| **CardRevealEntryView.cs** | 单个抽卡结果条目视图。 |
| **ShipyardPanel.cs** | 船坞/卡牌仓库面板。 |
| **ShipyardLazyVerticalList.cs** | 船坞卡牌列表懒加载视图。 |
| **ShipyardCardSlotView.cs** | 船坞卡牌格子视图。 |
| **InventoryPanel.cs** | 背包面板，读取并分页展示 `InventoryStore` 数据。 |
| **InventorySlotView.cs** | 背包道具格子视图。 |
| **FleetPanel.cs** | 编队面板，读取并展示 `FleetStore` 数据。 |
| **FleetCardSlotView.cs** | 编队卡牌格子视图。 |
| **ActivityPanel.cs** | 活动入口面板。 |
| **LevelSelectPanel.cs** | 关卡选择入口面板。 |
| **LevelAreaSelectPanel.cs** | 关卡区域选择面板。 |
| **LevelAreaInfoCardView.cs** | 关卡区域信息卡片视图。 |
| **LevelStageSelectPanel.cs** | 关卡节点选择面板。 |

#### Game/Debug/

开发期调试工具。

| 脚本 | 功能 |
|------|------|
| **UIRaycastDebugHotkey.cs** | UI 射线调试热键，辅助排查 UI 点击命中问题。 |

#### Game/Core/

编辑器与资产辅助工具。

| 脚本 | 功能 |
|------|------|
| **ScriptableObjectAssetRenameUtility.cs** | ScriptableObject 资产重命名工具，按配置字段规范化资源文件名。 |
