# 脚本结构图

> 本文档随 `Assets/Scripts/` 下脚本的增改而更新，用于快速查看当前重制版工程的分层、目录职责与脚本职责。

## 分层概览

```
启动/场景入口层     Game/Bootstrap/Presentation
                         ↓
应用服务与本地数据层 Game/Common, Game/Card/Application, Game/Inventory/Application
                         ↓
领域配置层          Game/Card/Domain, Game/Inventory/Domain, Game/Level/Domain
                         ↓
表现层              Game/UI/Presentation, Game/Debug
                         ↓
编辑器辅助          Game/Core
```

- **启动/场景入口层**：负责启动场景校正、进入游戏场景后的默认面板初始化，以及退出/切后台时的统一保存入口。
- **应用服务与本地数据层**：负责账号、本地加密存档、Resources 加载、建造抽卡、卡牌仓库、道具仓库与编队数据。
- **领域配置层**：以 ScriptableObject 保存卡牌、卡池、道具、关卡区域与关卡按钮等静态配置。
- **表现层**：负责标题、登录、主界面、建造、仓库、船坞、编队、选关等 UI 面板与视图组件。
- **编辑器辅助**：仅在编辑器环境下辅助同步 ScriptableObject 资产命名。

## 目录与脚本说明

### Assets/Scripts/Game/

重制版游戏脚本根目录，按 Bootstrap、Common、Card、Inventory、Level、UI、Debug、Core 等模块拆分。

---

### Game/Bootstrap/Presentation

启动与场景入口表现层，负责场景校正和默认 UI 展示。

| 脚本 | 功能 |
|------|------|
| **GameBootstrap.cs** | 游戏启动器：跨场景常驻，确保从标题场景进入，并在退出/切后台时调用统一保存服务。 |
| **GameSceneManager.cs** | 游戏场景管理器：进入游戏场景后初始化默认主界面。 |

---

### Game/Common

通用基础设施与跨模块服务，包括资源路径、Resources 加载、本地安全、账号与统一保存。

| 脚本 | 功能 |
|------|------|
| **GameResourcePaths.cs** | 集中定义 Resources 路径常量，减少各模块魔法字符串。 |
| **GameResourceLoader.cs** | Resources 加载门面：集中缓存与告警日志。 |

#### Game/Common/Auth

账号服务与多账号数据目录隔离。

| 脚本 | 功能 |
|------|------|
| **AccountStore.cs** | 本地账号库：注册、登录、登出、记住密码；提供当前账号存储键与账号独立玩家数据目录。账号库读取失败时禁止写回默认库，避免清空账号。 |

#### Game/Common/Currency

玩家货币资源存储。

| 脚本 | 功能 |
|------|------|
| **CurrencyStore.cs** | 加密保存金币、钻石、船票；缓存绑定当前账号，读档失败后禁止自动保存覆盖旧档。 |

#### Game/Common/Save

统一保存入口。

| 脚本 | 功能 |
|------|------|
| **GameDataSaveService.cs** | 退出或切后台时统一触发账号、资源、仓库、卡牌仓库与编队保存。 |

#### Game/Common/Security

本地数据加解密。

| 脚本 | 功能 |
|------|------|
| **LocalDataCrypto.cs** | AES-CBC 加解密工具：为账号库和 UserData 明文 JSON 提供本地加密字节流。 |

---

### Game/Card/Application

卡牌相关应用服务与玩家卡牌数据持久化。

| 脚本 | 功能 |
|------|------|
| **BuildService.cs** | 建造服务：校验并扣减资源，按卡池权重抽卡，写入卡牌仓库并返回抽卡结果。 |
| **CardCollectionStore.cs** | 玩家卡牌仓库加密存储：按当前账号隔离，支持旧版单账号共享档迁移，读档失败后禁止覆盖旧档。 |
| **FleetStore.cs** | 玩家编队加密存储：维护多套卡组与每组最多 6 张卡牌，按当前账号隔离并保护损坏旧档。 |

### Game/Card/Domain

卡牌、阵营、卡池与配置数据库等静态领域配置。

| 脚本 | 功能 |
|------|------|
| **CardConfigSO.cs** | 单张舰娘/卡牌配置：稀有度、中文名、英文名、数值与图标路径规则。 |
| **CardConfigDatabaseSO.cs** | 卡牌配置数据库：按 cardId 查询卡牌配置。 |
| **ShipFaction.cs** | 舰娘与建造卡池所属阵营枚举。 |
| **BuildPoolConfigSO.cs** | 单个建造卡池配置：横幅、消耗、掉落权重等。 |
| **BuildPoolDatabaseSO.cs** | 卡池数据库：维护可选建造卡池列表。 |

---

### Game/Inventory/Application

玩家道具仓库的应用层持久化。

| 脚本 | 功能 |
|------|------|
| **InventoryStore.cs** | 玩家道具仓库加密存储：按当前账号隔离，提供增加、消耗、删除接口，读档失败后禁止覆盖旧档。 |

### Game/Inventory/Domain

道具静态配置。

| 脚本 | 功能 |
|------|------|
| **ItemConfigSO.cs** | 单个道具配置：基础信息与图标资源路径。 |
| **ItemConfigDatabaseSO.cs** | 道具配置库：按 itemId 查询道具配置。 |

---

### Game/Level/Domain

关卡区域、关卡按钮和模式配置。

| 脚本 | 功能 |
|------|------|
| **LevelAreaConfigSO.cs** | 单个可挑战区域配置，可被区域数据库引用。 |
| **LevelAreaDatabaseSO.cs** | 关卡区域数据库：维护常驻与活动两套区域列表，并定义 LevelMode。 |
| **LevelStageConfigSO.cs** | 单个关卡按钮配置：可被多个区域复用。 |

---

### Game/UI/Presentation

UI 基础设施、面板名称和标题/游戏场景各面板。

| 脚本 | 功能 |
|------|------|
| **BasePanel.cs** | UI 面板基类：启用/禁用时向 UIPanelRegistry 注册或注销。 |
| **PanelNames.cs** | 面板名称与场景名称常量。 |
| **UIPanelRegistry.cs** | 场景内 UI 面板注册表：栈式打开、返回、回主界面，并支持换场景加载。 |

#### Game/UI/Presentation/TitleScene

标题与登录流程。

| 脚本 | 功能 |
|------|------|
| **TitlePanel.cs** | 标题面板：处理登录入口、退出账号、设置预留和退出游戏。 |
| **LoginPanel.cs** | 登录面板：处理账号输入、注册、登录、记住密码与返回标题。 |

#### Game/UI/Presentation/GameScene

游戏主场景的功能面板与视图组件。

| 脚本 | 功能 |
|------|------|
| **MainPanel.cs** | 主界面：战斗入口、仓库、船坞、活动等入口，并展示部分资源。 |
| **BuildPanel.cs** | 建造面板：卡池切换、资源展示、单抽/十连抽与领卡展示入口。 |
| **BuildPoolDetailView.cs** | 建造卡池详情视图：横幅、名称、消耗、切换按钮容器和抽卡按钮引用。 |
| **BuildPoolButtonView.cs** | 卡池切换按钮视图：显示卡池名并响应点击。 |
| **CardRevealPanel.cs** | 领卡展示面板：横向叠放抽卡结果，逐张滑出后关闭。 |
| **CardRevealEntryView.cs** | 单张领卡结果视图：显示头像、名称与当前张高亮。 |
| **InventoryPanel.cs** | 仓库面板：分页显示道具，支持返回主界面与回标题。 |
| **InventorySlotView.cs** | 仓库格子视图：绑定单个道具数据到 UI。 |
| **ShipyardPanel.cs** | 船坞面板：展示玩家卡牌仓库，使用纵向网格列表并支持返回。 |
| **ShipyardLazyVerticalList.cs** | 船坞卡牌网格：按稀有度实例化槽位预制体并自适应列数。 |
| **ShipyardCardSlotView.cs** | 船坞舰娘槽位视图：展示名称、头像与稀有度。 |
| **FleetPanel.cs** | 编队面板：展示多套卡组，支持切换卡组、返回和修改入口。 |
| **FleetCardSlotView.cs** | 编队卡牌槽位视图：展示卡牌名称、头像与编号。 |
| **LevelSelectPanel.cs** | 选关入口面板：提供常驻、活动、返回与主界面按钮。 |
| **LevelAreaSelectPanel.cs** | 区域选择面板：横向滚动展示常驻/活动区域信息。 |
| **LevelAreaInfoCardView.cs** | 区域信息卡片视图：绑定区域标题、描述等文本。 |
| **LevelStageSelectPanel.cs** | 区域关卡选择面板：纵向生成关卡按钮列表。 |
| **ActivityPanel.cs** | 活动面板：通过 UIPanelRegistry 参与同场景栈式导航。 |
