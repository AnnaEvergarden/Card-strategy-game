# 脚本结构图

> 本文档随 `Assets/Scripts/` 下脚本的增改而更新，用于快速查看分层与各脚本/文件夹职责。

## 分层概览

```
启动/场景层      Game/Bootstrap/Presentation
                    ↓
UI 表现层        Game/UI/Presentation
                    ↓
应用服务层      Game/Card/Application, Game/Inventory/Application, Game/Common/Currency,
                Game/Common/Auth, Game/Common/Save
                    ↓
领域配置层      Game/Card/Domain, Game/Inventory/Domain, Game/Level/Domain
                    ↓
公共基础设施    Game/Common, Game/Common/Security, Game/Core, Game/Debug
```

- **启动/场景层**：负责入口场景校正、场景级默认面板与退出/后台保存。
- **UI 表现层**：负责面板栈、按钮事件、列表条目、抽卡展示、舰队/仓库/关卡等界面刷新；通过应用服务读写数据。
- **应用服务层**：负责账号、货币、背包、卡牌仓库、编队、抽卡等本地数据和业务用例。
- **领域配置层**：使用 ScriptableObject 或配置对象描述卡牌、卡池、道具、关卡区域/关卡。
- **公共基础设施**：提供资源路径、Resources 加载、加密、编辑器辅助和调试热键等横向能力。

## 目录与脚本说明

### Assets/Scripts/Game/

当前重制版脚本根目录，按 Bootstrap / Common / Card / Inventory / Level / UI 等模块组织。

---

### Bootstrap/Presentation（启动与场景）

| 脚本 | 功能 |
|------|------|
| **GameBootstrap.cs** | 运行时保持启动器常驻，强制从标题场景进入，并在退出/后台时调用统一保存服务。 |
| **GameSceneManager.cs** | 游戏场景入口，确保当前场景按面板注册表显示默认主界面栈。 |

---

### Common（公共基础设施与共享服务）

| 脚本 | 功能 |
|------|------|
| **GameResourceLoader.cs** | 统一加载卡牌/卡池/道具/关卡数据库、Sprite 和 UI 预制体，并缓存常用资源。 |
| **GameResourcePaths.cs** | 集中维护 Resources 下数据库、图标、预制体等路径常量。 |

#### Common/Auth

| 脚本 | 功能 |
|------|------|
| **AccountStore.cs** | 本地账号注册、登录、退出、记住密码与当前账号状态；账号库使用共享数据路径，登录切换时清空进度缓存。 |

#### Common/Currency

| 脚本 | 功能 |
|------|------|
| **CurrencyStore.cs** | 按当前账号隔离保存金币、钻石、船票，并提供增加与一次性消耗接口。 |

#### Common/Save

| 脚本 | 功能 |
|------|------|
| **GameDataSaveService.cs** | 退出/后台时统一保存当前登录账号的货币、背包、卡牌仓库与编队缓存。 |
| **LocalUserDataPaths.cs** | 统一生成 `persistentDataPath/UserData` 下的共享账号库路径与当前账号进度路径，并支持旧账号库位置迁移。 |

#### Common/Security

| 脚本 | 功能 |
|------|------|
| **LocalDataCrypto.cs** | 使用 AES-CBC/PKCS7 加解密本地 JSON 存档字节。 |

---

### Card（卡牌、卡池与编队）

#### Card/Domain

| 脚本 | 功能 |
|------|------|
| **CardConfigSO.cs** | 单张卡牌配置：ID、显示名、英文名、阵营、稀有度、资源路径等。 |
| **CardConfigDatabaseSO.cs** | 卡牌配置数据库，提供卡牌配置列表。 |
| **BuildPoolConfigSO.cs** | 单个建造卡池配置：消耗、掉落条目、权重与抽取逻辑。 |
| **BuildPoolDatabaseSO.cs** | 卡池数据库，提供所有建造卡池配置。 |
| **ShipFaction.cs** | 舰船阵营枚举。 |

#### Card/Application

| 脚本 | 功能 |
|------|------|
| **BuildService.cs** | 建造/抽卡服务：校验资源、扣费、按卡池抽取并写入卡牌仓库。 |
| **CardCollectionStore.cs** | 按当前账号隔离保存玩家拥有的卡牌列表，并提供增加/消耗/删除接口。 |
| **FleetStore.cs** | 按当前账号隔离保存多套编队，并在首次无编队时从卡牌仓库生成默认卡组。 |

---

### Inventory（道具仓库）

#### Inventory/Domain

| 脚本 | 功能 |
|------|------|
| **ItemConfigSO.cs** | 单个道具配置：ID、名称、描述、图标路径等。 |
| **ItemConfigDatabaseSO.cs** | 道具配置数据库，提供道具配置列表。 |

#### Inventory/Application

| 脚本 | 功能 |
|------|------|
| **InventoryStore.cs** | 按当前账号隔离保存道具列表，并提供增加、消耗、删除接口。 |

---

### Level（关卡配置）

#### Level/Domain

| 脚本 | 功能 |
|------|------|
| **LevelAreaConfigSO.cs** | 关卡区域配置：区域 ID、名称、背景、描述与关卡列表。 |
| **LevelAreaDatabaseSO.cs** | 关卡区域数据库，提供所有区域配置。 |
| **LevelStageConfigSO.cs** | 单个关卡配置：关卡 ID、名称、推荐等级、消耗/奖励等。 |

---

### UI/Presentation（界面表现与面板栈）

| 脚本 | 功能 |
|------|------|
| **BasePanel.cs** | 面板基类：维护 PanelName，并提供 Show/Hide 生命周期入口。 |
| **PanelNames.cs** | 面板名常量，避免硬编码字符串分散在按钮逻辑中。 |
| **UIPanelRegistry.cs** | 面板注册表与栈管理：注册场景面板、Push/Pop/ClearAndPush、加载场景默认栈。 |

#### UI/Presentation/TitleScene

| 脚本 | 功能 |
|------|------|
| **TitlePanel.cs** | 标题界面入口，处理登录入口、设置占位与退出。 |
| **LoginPanel.cs** | 登录面板，处理账号输入、注册、登录、记住密码与进入游戏场景。 |

#### UI/Presentation/GameScene

| 脚本 | 功能 |
|------|------|
| **MainPanel.cs** | 游戏主界面，展示资源并跳转活动、建造、船坞、仓库、编队、战斗入口。 |
| **ActivityPanel.cs** | 活动入口面板。 |
| **BuildPanel.cs** | 建造面板，展示卡池、触发建造服务并打开领卡展示。 |
| **BuildPoolButtonView.cs** | 卡池按钮条目，绑定卡池名称、描述与点击回调。 |
| **BuildPoolDetailView.cs** | 卡池详情视图，展示消耗、说明与掉落信息。 |
| **CardRevealPanel.cs** | 抽卡结果展示面板，按堆叠条目逐张滑出并关闭。 |
| **CardRevealEntryView.cs** | 单张抽卡展示条目，绑定卡牌头像、名称与当前张视觉状态。 |
| **ShipyardPanel.cs** | 船坞面板，展示玩家卡牌仓库并驱动懒加载列表。 |
| **ShipyardLazyVerticalList.cs** | 船坞虚拟/懒加载列表，根据滚动位置复用条目。 |
| **ShipyardCardSlotView.cs** | 船坞卡牌槽位视图，绑定卡牌配置与数量。 |
| **InventoryPanel.cs** | 仓库面板，展示玩家道具列表。 |
| **InventorySlotView.cs** | 仓库道具槽位视图，绑定道具图标、名称与数量。 |
| **FleetPanel.cs** | 编队面板，展示多套卡组并支持上一套/下一套切换。 |
| **FleetCardSlotView.cs** | 编队卡牌槽位视图，绑定槽位序号、卡牌 ID 与配置显示。 |
| **LevelSelectPanel.cs** | 战斗入口面板，进入区域/关卡选择流程。 |
| **LevelAreaSelectPanel.cs** | 关卡区域选择面板，展示区域按钮与区域信息卡。 |
| **LevelAreaInfoCardView.cs** | 区域信息卡视图，绑定区域名称、描述、背景等。 |
| **LevelStageSelectPanel.cs** | 区域内关卡选择面板，展示关卡条目与返回逻辑。 |
