# 脚本结构图

> 本文档随 `Assets/Scripts/` 下脚本的增改而更新，用于快速查看当前重制版分层、目录职责与脚本职责。

## 分层概览

```
入口/启动层        Game/Bootstrap/Presentation
                       ↓
基础设施层          Game/Common（账号、资源加载、加密、保存路径与自动保存）
                       ↓
应用/领域层         Game/Card, Game/Inventory, Game/Level
                       ↓
表现层              Game/UI/Presentation（面板注册、标题场景、主游戏场景）
                       ↓
工具/调试层         Game/Core, Game/Debug
```

- **入口/启动层**：负责启动场景校正与场景切换封装。
- **基础设施层**：提供账号、本地加密、玩家数据路径、资源加载、货币与统一自动保存。
- **应用/领域层**：卡牌、建造、编队、背包、关卡等数据结构与应用服务。
- **表现层**：所有 UI 面板、面板栈、按钮入口和列表视图。
- **工具/调试层**：编辑器辅助、调试热键等不直接承载主业务状态的脚本。

## 目录与脚本说明

### Assets/Scripts/

当前脚本根目录以 `Game/` 为主，按 Bootstrap、Common、Card、Inventory、Level、UI 等模块组织。

---

### Game/Bootstrap/Presentation

启动与场景入口表现层，负责游戏进入点和场景切换。

| 脚本 | 功能 |
|------|------|
| **GameBootstrap.cs** | 运行时常驻启动器：确保从标题场景进入，并在退出/切后台时触发统一保存。 |
| **GameSceneManager.cs** | 场景加载入口封装：提供标题、主游戏、战斗等场景跳转方法。 |

---

### Game/Common

跨模块基础设施，包含账号、本地加密、资源路径、资源加载与玩家数据保存。

| 脚本 | 功能 |
|------|------|
| **GameResourceLoader.cs** | Resources 加载工具：按约定路径加载卡牌、道具、关卡、预制体等资源。 |
| **GameResourcePaths.cs** | Resources 路径常量集中定义，避免各 UI/服务硬编码路径。 |

#### Game/Common/Auth

| 脚本 | 功能 |
|------|------|
| **AccountStore.cs** | 本地账号库：注册、登录、退出、当前账号与记住密码，账号库保存在全局 `UserData/account.dat`。 |

#### Game/Common/Currency

| 脚本 | 功能 |
|------|------|
| **CurrencyStore.cs** | 玩家货币持久化：金币、钻石、船票的读取、保存、增加与原子消耗；按当前账号目录隔离。 |

#### Game/Common/Save

| 脚本 | 功能 |
|------|------|
| **GameDataSaveService.cs** | 统一自动保存入口：退出/切后台时仅保存当前登录账号的玩家进度。 |
| **PlayerDataPath.cs** | 玩家进度路径工具：根据当前账号生成 `UserData/Players/{账号键}`，供各 Store 隔离读写。 |

#### Game/Common/Security

| 脚本 | 功能 |
|------|------|
| **LocalDataCrypto.cs** | 本地数据 AES 加解密工具：账号库与玩家进度文件写盘前统一加密。 |

---

### Game/Card

卡牌、建造池、卡牌仓库与编队相关领域/应用逻辑。

#### Game/Card/Domain

| 脚本 | 功能 |
|------|------|
| **ShipFaction.cs** | 舰船阵营枚举。 |
| **CardConfigSO.cs** | 单张卡牌配置：id、名称、稀有度、阵营、数值与图标等。 |
| **CardConfigDatabaseSO.cs** | 卡牌配置数据库：集中持有可检索的卡牌配置列表。 |
| **BuildPoolConfigSO.cs** | 建造池配置：消耗、展示信息与掉落项。 |
| **BuildPoolDatabaseSO.cs** | 建造池数据库：集中持有所有建造池配置。 |

#### Game/Card/Application

| 脚本 | 功能 |
|------|------|
| **BuildService.cs** | 建造应用服务：读取卡池、扣除资源、抽取卡牌、回滚无效结果。 |
| **CardCollectionStore.cs** | 玩家卡牌仓库持久化：按账号隔离保存拥有卡牌，并在数据异常时阻止默认数据覆盖旧档。 |
| **FleetStore.cs** | 玩家编队持久化：按账号隔离保存多套卡组，并从卡牌仓库生成默认编队。 |
