# 脚本结构图

> 本文档随 `Assets/Scripts/` 下脚本的增改而更新，用于快速查看当前重制版工程的分层与职责。

## 分层概览

```text
启动/场景层        Game/Bootstrap/Presentation
                       ↓
应用与数据服务层    Game/Common, Game/Card/Application, Game/Inventory/Application
                       ↓
领域配置层          Game/Card/Domain, Game/Inventory/Domain, Game/Level/Domain
                       ↓
表现/UI 层          Game/UI/Presentation
                       ↓
工具/编辑器层       Game/Core, Game/Debug
```

- **启动/场景层**：负责强制从标题场景进入、场景切换与退出保存。
- **应用与数据服务层**：负责账号、加密、本地玩家进度、货币、道具、卡牌仓库、编队与建造流程。
- **领域配置层**：负责 ScriptableObject 配置与数据库索引，不直接处理 UI。
- **表现/UI 层**：负责标题、主界面、仓库、船坞、编队、建造、选关等用户交互。
- **工具/编辑器层**：负责 ScriptableObject 资源重命名、UI 射线调试等辅助能力。

## 目录与脚本说明

### Assets/Scripts/

项目 C# 脚本根目录。当前重制版主要集中在 `Game/` 下，旧版 `Core/Services/UI` 目录已被最新提交替换。

### Game/Bootstrap/Presentation

启动与场景切换入口。

| 脚本 | 功能 |
|------|------|
| **GameBootstrap.cs** | 游戏启动器：运行时强制回到标题场景，并在退出/后台时调用统一保存。 |
| **GameSceneManager.cs** | 游戏场景管理入口：封装返回标题、进入战斗等场景跳转。 |

### Game/Common

跨系统公共基础设施、资源路径与资源加载。

| 脚本 | 功能 |
|------|------|
| **GameResourcePaths.cs** | 集中维护 Resources 相对路径常量与头像路径拼接。 |
| **GameResourceLoader.cs** | 统一加载 ScriptableObject 数据库、Sprite、Prefab，并提供缓存与缺失告警。 |

#### Game/Common/Auth

本地账号数据库与当前登录状态。

| 脚本 | 功能 |
|------|------|
| **AccountStore.cs** | 本地注册、登录、登出、记住密码与当前账号持久化；账号库保存为加密 `account.dat`。 |

#### Game/Common/Currency

玩家资源数据。

| 脚本 | 功能 |
|------|------|
| **CurrencyStore.cs** | 按当前账号持久化金币、钻石、船票；提供增加与原子消耗接口，并防止未登录/切号写错档。 |

#### Game/Common/Save

玩家进度保存入口与账号隔离路径。

| 脚本 | 功能 |
|------|------|
| **GameDataSaveService.cs** | 统一保存货币、仓库、卡牌仓库、编队；未登录时跳过，避免覆盖玩家进度。 |
| **UserDataPathService.cs** | 根据当前账号生成 `UserData/Users/<账号哈希>/` 路径，并提供旧版共享文件迁移路径。 |

#### Game/Common/Security

本地数据加解密。

| 脚本 | 功能 |
|------|------|
| **LocalDataCrypto.cs** | AES-CBC/PKCS7 加解密本地 JSON 数据，密钥由项目种子与设备标识派生。 |

### Game/Card/Application

卡牌相关应用服务与玩家卡牌进度。

| 脚本 | 功能 |
|------|------|
| **BuildService.cs** | 建造抽卡用例：校验并扣资源、按卡池权重抽取、写入卡牌仓库。 |
| **CardCollectionStore.cs** | 按当前账号持久化卡牌仓库，并提供增加、消耗、删除卡牌接口。 |
| **FleetStore.cs** | 按当前账号持久化多套编队，并保证每套卡组不超过 6 张卡牌。 |

### Game/Card/Domain

卡牌、阵营与建造池配置。

| 脚本 | 功能 |
|------|------|
| **BuildPoolConfigSO.cs** | 建造卡池配置：卡池 ID、阵营、消耗、掉落条目和权重。 |
| **BuildPoolDatabaseSO.cs** | 卡池数据库：集中引用全部卡池配置。 |
| **CardConfigSO.cs** | 单张卡牌配置：ID、名称、阵营、稀有度、立绘/头像等静态数据。 |
| **CardConfigDatabaseSO.cs** | 卡牌配置数据库：按 cardId 查找卡牌配置。 |
| **ShipFaction.cs** | 舰船阵营枚举。 |

### Game/Inventory/Application

玩家道具仓库进度。

| 脚本 | 功能 |
|------|------|
| **InventoryStore.cs** | 按当前账号持久化道具仓库，并提供增加、消耗、删除道具接口。 |

### Game/Inventory/Domain

道具配置。

| 脚本 | 功能 |
|------|------|
| **ItemConfigSO.cs** | 单个道具配置：ID、显示名、描述、图标等。 |
| **ItemConfigDatabaseSO.cs** | 道具配置数据库：按 itemId 查找道具配置。 |

### Game/Level/Domain

选关与关卡区域配置。

| 脚本 | 功能 |
|------|------|
| **LevelAreaConfigSO.cs** | 关卡区域配置：区域 ID、名称、背景、包含关卡等。 |
| **LevelAreaDatabaseSO.cs** | 区域数据库：集中引用全部区域配置。 |
| **LevelStageConfigSO.cs** | 单个关卡配置：关卡 ID、名称、描述、推荐战力等。 |

### Game/UI/Presentation

UI 基础类、面板注册表和场景 UI。

| 脚本 | 功能 |
|------|------|
| **BasePanel.cs** | UI 面板基类：封装显示、隐藏、注册与面板名。 |
| **PanelNames.cs** | 面板名与场景名常量。 |
| **UIPanelRegistry.cs** | 全局 UI 面板注册、栈式导航、场景加载、退出游戏。 |

#### Game/UI/Presentation/TitleScene

标题与登录流程。

| 脚本 | 功能 |
|------|------|
| **TitlePanel.cs** | 标题面板：登录入口、登出、设置占位与退出游戏。 |
| **LoginPanel.cs** | 登录面板：注册、登录、记住密码与进入游戏场景。 |

#### Game/UI/Presentation/GameScene

主场景面板、仓库、船坞、编队、建造、活动与选关。

| 脚本 | 功能 |
|------|------|
| **ActivityPanel.cs** | 活动入口面板。 |
| **BuildPanel.cs** | 建造面板：展示卡池、执行单抽/十连并打开揭示面板。 |
| **BuildPoolButtonView.cs** | 卡池按钮视图：绑定卡池名称与选择回调。 |
| **BuildPoolDetailView.cs** | 卡池详情视图：展示当前卡池消耗与说明。 |
| **CardRevealEntryView.cs** | 单张抽卡结果视图。 |
| **CardRevealPanel.cs** | 抽卡结果面板：加载卡牌配置并展示本次获得的卡牌。 |
| **FleetCardSlotView.cs** | 编队卡槽视图：绑定卡牌配置和槽位状态。 |
| **FleetPanel.cs** | 编队面板：读取编队数据、展示卡组并管理默认打开状态。 |
| **InventoryPanel.cs** | 道具仓库面板：读取玩家道具并根据配置展示列表。 |
| **InventorySlotView.cs** | 道具槽位视图：绑定道具数量、名称与图标。 |
| **LevelAreaInfoCardView.cs** | 区域信息卡片视图。 |
| **LevelAreaSelectPanel.cs** | 区域选择面板：展示区域列表并进入关卡选择。 |
| **LevelSelectPanel.cs** | 选关入口面板：常规/活动关卡入口。 |
| **LevelStageSelectPanel.cs** | 关卡选择面板：展示指定区域下的关卡。 |
| **MainPanel.cs** | 游戏主界面：展示资源并提供战斗、仓库、船坞、编队、建造、活动入口。 |
| **ShipyardCardSlotView.cs** | 船坞卡牌槽位视图：绑定卡牌数量、稀有度和头像。 |
| **ShipyardLazyVerticalList.cs** | 船坞懒加载纵向列表：复用卡槽视图显示大量卡牌。 |
| **ShipyardPanel.cs** | 船坞面板：读取卡牌仓库并驱动懒加载列表。 |

### Game/Core

编辑器与资源维护工具。

|------|------|
